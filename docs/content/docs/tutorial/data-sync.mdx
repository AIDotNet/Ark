顶栏 **数据同步** 打开同步中心。同步能力分两层：**同步配置（Profile）** 管理可复用、可定时的同步任务；**新建同步向导** 一次性走完 源 → 目标 → 范围 → 审阅 → 执行。

![同步中心](/images/19-sync-center.png)

同步中心分「同步配置」与「任务历史」两个 Tab。配置卡片上可直接运行 / 编辑 / 复制 / 删除，卡片内嵌定时调度开关（本图为一个指向已删除连接的旧配置，字段显示为「未知连接」）。

## 1. 第一步：源与目标

![向导第 1 步](/images/20-sync-step1-source-target.png)

- 左右两侧分别选择 **源** 与 **目标** 的连接和数据库
- 目标为 PostgreSQL 时可额外指定「目标 schema」（跨方言同步默认 `public`）
- 源 = 目标会被直接拦截

## 2. 第二步：范围与选项

![向导第 2 步](/images/21-sync-step2-scope-options.png)

**同步模式**：

| 模式 | 说明 |
|---|---|
| 仅结构 | 只做类型映射 + 函数翻译 + 结构 Diff |
| 结构 + 数据 | 同步结构并复制数据 |

**数据选项**（结构 + 数据时）：

- **数据方式**：全量复制 / 行级 Diff（分块）
- **冲突策略**：冲突时报错 / 复制前清空目标表 / 跳过已存在（需主键）
- 开关：删除目标多余行（仅行级 Diff）、对齐自增·序列、大表索引后建

**通用选项**：删除目标端多余表（破坏性，生成 DROP 前需确认）、校验（关闭 / 行数+抽样）、批次（默认 1000）、分块（默认 2000）、并行表数（默认 2，最大 8）。

**选择表**：按表勾选同步范围（视图以「视图」Badge 标注；全选默认不含视图）。底部「**先对比再同步**」开关见下文第 5 节。

## 3. 第三步：审阅（计划预览）

![向导第 3 步：计划审阅](/images/22-sync-step3-plan-review.png)

点 **生成同步计划** 后进入审阅页。计划是一个**完整快照**——「N 张表 · 快照 xxxx（执行时使用此快照，不重新规划）」，预览所见即执行所得：

- 每表一张卡片：新建 / 已存在（Diff）、数据方式与预估行数、无主键标记
- **转换问题三级提示**：error（默认忽略该项）/ warning（原样复制，请人工确认）/ hint；例如 SQLite 忽略 DECIMAL 精度、无法翻译的默认值表达式
- **缺失扩展检查**：目标缺 `pgcrypto` / `uuid-ossp` 时给出 `CREATE EXTENSION IF NOT EXISTS …` 建议
- **逐条 DDL 动作可勾选跳过**；破坏性动作（DROP 等）以红色 Badge 标注且**默认勾选跳过**，必须显式打开「确认执行破坏性动作」才会执行
- 每条动作可展开查看 SQL 全文
- 可勾选「**保存为同步配置（Profile）**」并设置 cron 定时（不调度 / 每小时 / 每天 09:00 / 每天 22:00 / 每周一 09:00 / 自定义 5 段 cron）

确认后点 **提交执行**。

## 4. 第四步：执行

![向导第 4 步：执行与报告](/images/23-sync-step4-run-report.png)

- 状态 Badge + 当前表 + 行级进度 + 百分比
- **实时日志**自动滚动；**报告表**逐表列出 DDL 成功/失败、插入/更新/删除行数、校验结果、耗时、状态
- 运行中可 **取消**（在批次/分块边界生效）；失败任务可 **续传**（从断点继续，跳过已完成表与动作）或 **重跑**；**导出脚本** 可下载本次实际执行的 SQL
- 执行进度通过 SSE 实时推送（断线自动降级轮询）

任务在后台执行，关掉向导不影响；之后可在「任务历史」查看。

## 5. 先对比再同步（行级 Diff）

![对比结果](/images/25-sync-compare-result.png)

打开「先对比再同步」后，第二步的按钮变为 **开始对比**。对比任务以**行哈希**逐块比对源与目标（跨方言值归一：时间统一 UTC、decimal 去尾零、布尔归一，避免「永动更新」误报），结果按表展示：`+新增 / ~更新 / -删除` 与「查看差异行」入口。

点 **由对比结果生成同步计划** 可把差异转为执行计划：

![由对比生成计划](/images/26-sync-compare-to-plan.png)

## 6. 查看差异行

任务历史 → 任务的 **查看** → 表卡片的 **查看差异行**：

![差异行查看器](/images/27-sync-diff-viewer.png)

新增 / 变更 / 删除三个 Tab（带计数），变更行以「目标旧值（划线）+ 源新值（高亮）」双列对比展示，分页游标加载。

## 7. 任务历史与定时调度

![任务历史](/images/24-sync-task-history.png)

- 历史列表展示每次任务的 状态（Completed / Failed / PartiallyFailed / Interrupted…）、时间与进度
- 已保存的 Profile 卡片支持：**▶ 立即运行**、编辑（带初始配置重新打开向导）、复制、删除、卡片内直接改 cron
- 定时任务由后台调度器每 30 秒扫描，按 cron 计算 `nextRun` 并显示在卡片上；错过不补跑；同 Profile 上一个任务未结束则跳过

## 断点续传机制

任务全量状态（含计划、断点：当前表、最后主键、已完成动作）定期落库；进程重启后遗留 Running 任务自动标记为 Interrupted，可通过 **续传** 从断点继续，**重跑** 则从头开始。
