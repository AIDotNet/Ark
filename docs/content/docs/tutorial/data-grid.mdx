单击树中的表名即可打开数据网格。以 `orders` 表（15 行示例数据）为例。

## 1. 浏览与分页

![数据网格](/images/06-data-grid.png)

- 表头显示列名 + 类型（如 `status TEXT`），NULL 值以斜体灰 `NULL` 展示
- 底部分页栏：总行数、每页行数（20/50/100/200/500）、首页/上一页/页码输入/下一页/末页
- 右下角显示列数、**主键**、已选行数
- 大数据量下表格虚拟滚动，万级行不卡顿
- 单元格右键：复制单元格 / 复制整行（JSON）

## 2. 筛选与排序

![筛选 + 排序](/images/07-data-grid-filter-sort.png)

**筛选**（网格顶部工具栏）：

1. 选择筛选列（如 `status`）
2. 选择操作符：`= ≠ > < ≥ ≤ 包含(like) 为空 非空`
3. 输入值后回车（数值/布尔列自动按类型转换）

可叠加多个筛选（AND），每个筛选生成一个可单独删除的 Badge。上图为 `status = completed` + 按 `total` 降序的效果。

**排序**：点击表头循环 **升序 → 降序 → 取消**，表头有方向指示。

## 3. 行内编辑（变更集模式）

![编辑单元格](/images/08-data-grid-edit.png)

1. **双击单元格**进入编辑（图中第一行 status 已改为 `shipped`，黄色高亮标记）
2. Enter 提交、Esc 取消；变更先记录在本地**变更集**，不会立即写库
3. 工具栏出现「**N 处变更 · 放弃 · 保存**」：确认无误后点 **保存**，全部变更（含新增/删除）在**一个事务**内提交；点 **放弃** 撤销全部

**新增行**：点「新增行」在网格顶部插入一行琥珀色可编辑临时行，填好后同样进入变更集。

**删除行**：勾选行（表头复选框全选本页）→「删除选中」，行变删除线样式，行首 × 可撤销；保存时统一提交。

## 4. 无主键表：自动只读

![无主键只读](/images/09-data-grid-nopk-readonly.png)

无主键的表（如演示库的 `audit_log`）右上角显示「**无主键 · 只读**」Badge，编辑/新增/删除入口自动禁用——因为行无法唯一定位，乐观更新不安全。需要编辑请先在表设计器中补主键。

## 常见问题

- **保存后部分失败**：变更集单事务提交，任何一条失败整体回滚，错误信息会标出具体原因（如唯一键冲突）
- **看不到新增行**：新增行插入在当前页顶部，筛选/排序不影响它
- **视图能编辑吗**：不能。视图只读浏览
