右键连接或数据库 → **新建查询**；也可用顶栏「新建查询」（沿用当前标签的连接上下文）或 ⌘K 命令面板。同一连接可开多个控制台标签，每个标签的 SQL 草稿独立持久化（刷新页面不丢）。

## 1. 编写 SQL

![SQL 控制台](/images/12-query-console.png)

- **CodeMirror 6 编辑器**：SQL 高亮、行号、⌘F 搜索、自动补全（表名/列名来自当前库的真实元数据）、**当前语句背景高亮**（DataGrip 风格，光标所在语句自动标底色）
- 工具栏从左到右：
  - **执行**（拆分按钮）：主钮执行「选中/光标所在语句」（⌘↩）；下拉可切换「执行整个脚本」（⌘⇧↩）
  - **格式化**（⇧⌥F，有选区只格式化选区）
  - **计划**：对当前语句生成 EXPLAIN 执行计划
  - **取消**：运行中出现，可中断长查询
  - **AI** 菜单（需在设置中启用，见[快捷键与设置](/docs/tutorial/shortcuts-settings)）
  - 库切换 / schema 切换（多 schema 时出现）/ 结果行上限（100–10000）/ 超时（10/30/60/300 秒）
  - **⭐ 保存** / **🕘 历史**

语句切分是手写的扫描器，正确处理 `--` 行注释、块注释、单双引号、反引号与 PG dollar-quoted 字符串；有选区时执行选区，光标在语句间隙时执行下一条。

## 2. 执行与多结果集

按 **⌘⇧↩** 执行整个脚本（两条 SELECT），得到多个结果集：

![多结果集](/images/13-query-results.png)

- 结果区按「结果 1 · N 行 / 结果 2 / 消息 / 计划」分标签
- 非查询语句（UPDATE/DDL）显示「执行成功 · 受影响 N 行」
- 结果网格支持：在结果中过滤（客户端）、点击表头排序、列宽拖拽、单元格右键（复制单元格 / 整行 JSON / **复制为 INSERT** / 复制整列 / 查看内容——长文本与 JSON 会格式化展示）
- 右上角 **导出**：当前结果集存为 CSV（带 BOM，Excel 友好）/ JSON / Markdown / INSERT 语句
- 底部状态显示结果集数量与耗时

## 3. 查询历史与收藏

![查询历史](/images/14-query-history.png)

点工具栏 **🕘** 打开面板，两个 Tab：

- **历史**：按连接过滤、关键字搜索、按 今天/昨天/日期 分组；绿点成功 / 红点失败，显示耗时与行数。**单击回填，双击直接执行**；⭐ 可收藏；同一 SQL 连续重复执行只更新时间戳不产生重复记录；每连接最多保留 500 条
- **已保存**：⭐ 保存的查询全局共享（不按连接隔离），同样单击回填、双击执行

## 4. 执行计划

选中语句 → **计划** 按钮（或对 `EXPLAIN` 语句直接执行）：

- PostgreSQL：`EXPLAIN (FORMAT JSON)` 美化输出
- MySQL：8+ 用 `EXPLAIN FORMAT=TREE`，旧版回退普通 EXPLAIN
- SQLite：`EXPLAIN QUERY PLAN`

只允许对查询类语句生成计划，防止 `EXPLAIN ANALYZE` 的副作用。

## 5. AI 助手（可选）

配置 AI 后（见[快捷键与设置](/docs/tutorial/shortcuts-settings)），AI 菜单提供三个能力，均会自动附带当前库的表结构上下文：

| 功能 | 说明 |
|---|---|
| 生成 SQL | 自然语言描述 → SQL，预览后插入编辑器 |
| 解释此查询 | 解释当前光标语句的作用 |
| AI 修复错误 | 执行失败后出现，把错误信息交给 AI，一键替换出错语句 |
