右键任意表 → **导入 / 导出**，两个 Tab 分别对应导出与导入。标题显示当前表（如 `main.audit_log`）。

## 1. 导出：CSV / JSON / SQL dump

![导出对话框](/images/17-export-dialog.png)

| 格式 | 说明 |
|---|---|
| CSV | RFC4180 转义，UTF-8，主键排序保证稳定分页，空表也输出表头 |
| JSON | 顶层数组，逐对象流式写出；二进制列转 base64 |
| SQL dump | 建表语句 + 逐行 INSERT（200 行缓冲）；字符串转义跟随源方言（MySQL 反斜杠翻倍，PG/SQLite 不翻倍），可直接在目标方言回放 |

- 「行数上限」留空 = 导出全部
- 全程**流式**写响应体，百万行不占内存
- 点击 **导出并下载** 即下载 `{table}.{format}` 文件

## 2. 导入：CSV / JSON

![导入对话框](/images/18-import-dialog.png)

1. 选择文件（`.csv` / `.json`）与格式（CSV 默认首行为表头；JSON 要求顶层数组、元素为对象）
2. 点击 **开始导入**

**行为规则**：

- **目标表已存在**：按列名映射插入；文件中多出的列忽略（计入警告），生成列自动跳过
- **目标表不存在**：按采样值（每列 ≤200 个非空样本）推断类型**自动建表**——全布尔→BOOLEAN、全整数→BIGINT、全数字→DOUBLE、全日期字符串→DATETIME、其余→TEXT；新表无主键、全可空
- 分批插入（默认 500 行/批，受方言参数上限约束），每批独立事务
- PostgreSQL 目标自动带 `::type` 参数 cast

![导入成功 toast](/images/28-import-success-toast.png)

成功后 toast 报告写入行数、是否自动建表与警告条数。

## 3. 典型用法

| 场景 | 做法 |
|---|---|
| 把一张表搬去另一个库 | 直接用[数据同步](/docs/tutorial/data-sync)；或导出 SQL dump 后在目标端 SQL 控制台回放 |
| 给开发库造数据 | 生产表导出 CSV → 开发库建同名表 → 导入 |
| Excel 数据入库 | Excel 另存 CSV → 对已有表导入（按表头列名映射）；或让 Ark 自动建表后再设计器里补主键/约束 |
| 备份单表 | 导出 SQL dump（含建表语句，方言安全） |
