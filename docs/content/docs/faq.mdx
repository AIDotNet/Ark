## 安装与启动

**Q：启动前端后页面空白 / 接口全 404？**
后端未启动或端口不对。前端把 `/api` 代理到 `http://localhost:5170`，先 `cd backend/src/Ark.Api && dotnet run`。

**Q：端口被占用？**
后端端口在 `backend/src/Ark.Api/Properties/launchSettings.json`；前端端口在 `frontend/vite.config.ts`。注意若用容器部署，容器内是 8080。

**Q：忘了管理员密码 / 需要登录？**
Ark v1 是单机单用户工具，**没有登录体系**；直接启动即用。请勿把端口暴露到公网。

## 连接

**Q：支持哪些数据库？**
PostgreSQL / MySQL / SQLite。其他数据库（如 SQL Server、Oracle）暂不支持；新增数据库需实现 `IDbProvider` + `IDdlGenerator` 两个接口（见[架构文档](/docs/architecture)）。

**Q：连接密码存在哪，安全吗？**
存于 `data/ark.db` 的 `connections.password_enc` 列，使用 ASP.NET Data Protection 加密（密钥默认在 `~/.aspnet/DataProtection-Keys`，容器内在 `/data`）。接口永不回显密码。

**Q：容器重建后连接密码失效？**
说明 Data Protection 密钥没有随卷持久化。官方镜像已设置 `HOME=/data` + `VOLUME /data`；自建镜像请保留这两个配置。

**Q：SQLite 可以连远程文件吗？**
不能。SQLite 是本机文件，填写的路径必须是 Ark 后端所在机器上的绝对路径。

## 数据网格与设计器

**Q：为什么这张表是只读的？**
两种情况：① 连接开了只读模式；② 表**无主键**（右上角「无主键 · 只读」），行无法唯一定位。给表补主键即可编辑。

**Q：双击改了单元格，数据库里怎么没变？**
变更先进入本地变更集（黄色高亮），需点工具栏 **保存** 才一次性事务提交；**放弃** 则全部撤销。

**Q：SQLite 表能改列类型吗？**
不能。SQLite 的 ALTER 子集只支持加列/删列/改名，其余变更 Ark 会提示「需重建表」。PostgreSQL / MySQL 无此限制。

**Q：能在界面里加索引/外键吗？**
设计器的索引/外键目前是**只读展示**。可用 SQL 控制台执行 DDL，或通过同步功能从已含索引的源库同步过来。

**Q：预览 DDL 里的黄色警告是什么意思？**
类型映射的**显式降级**。例如 SQLite 忽略 DECIMAL 精度、`jsonb` 映射到 MySQL 的 `json`。Ark 的原则是「绝不静默失败」——所有降级都在执行前列出，请人工确认。

## 数据同步

**Q：同步向导是几步？**
**4 步**：源与目标 → 范围与选项 → 审阅 → 执行。（注：仓库根 README 写的「5 步」为历史描述，以实际界面为准。）

**Q：跨方言同步（如 MySQL → PostgreSQL）支持吗？**
支持。结构经 Canonical 模型转换，默认值/生成列表达式按语义翻译（如 `now()` ↔ `CURRENT_TIMESTAMP`）；无法翻译的表达式会在计划中明确列出（error 忽略该项 / warning 原样复制），目标缺扩展（如 `pgcrypto`）会给出一键安装建议。

**Q：全量复制和行级 Diff 怎么选？**
- 全量复制：目标表可整体覆盖（配合「复制前清空」策略最干净），速度最快（PG COPY / MySQL LOAD DATA）
- 行级 Diff：只搬运差异行，适合定时增量对齐；需要主键，无主键表自动回退全量

**Q：为什么行级 Diff 跑完总显示有些行被「更新」？**
常见于时间/精度类型。Ark 已按目标列类型做跨方言归一（UTC 时间、decimal 去尾零等）；若仍出现，检查两端列类型是否一致（比如一边 `datetime` 一边 `timestamptz` 会引入时区语义差）。

**Q：DROP 语句会不会静默执行？**
不会。破坏性动作（DROP TABLE/COLUMN 等）在计划中红标、**默认勾选跳过**，且必须显式打开「确认执行破坏性动作」开关才会执行。

**Q：同步中途断了 / 服务重启了怎么办？**
任务断点定期落库，重启后遗留任务标记为 Interrupted；在任务历史中点 **续传** 从断点继续（跳过已完成表与动作），**重跑** 则从头执行。

**Q：定时任务到点没跑？**
调度使用**服务器本地时区**；调度器每 30 秒扫描一次；错过触发不补跑；同一 Profile 上一个任务未结束时跳过。可在 Profile 卡片查看「下次运行时间」核对。

**Q：哪里能看到本次同步实际执行的 SQL？**
任务详情 → **导出脚本**，下载 `ark-sync-*.sql`。

## SQL 控制台

**Q：⌘↩ 执行的是哪条语句？**
有选区执行选区；无选区执行光标所在语句（注释、引号、PG dollar-quote 均正确切分）；光标在语句间隙时执行下一条；空文档执行整篇。**⌘⇧↩** 永远执行整个脚本。

**Q：结果太多浏览器卡？**
控制台有「结果行上限」（100–10000，服务端硬上限 100000）；结果网格为虚拟滚动。大批量取数请用表的「导出」功能（流式，不经浏览器内存）。

**Q：AI 菜单是灰的？**
先在 ⚙ 设置里启用 AI 助手并配置 OpenAI 兼容接口（Base URL / 模型 / API Key），用「测试连接」验证。任何 OpenAI 兼容服务（Azure / Ollama / 代理网关）均可。

## 导入导出

**Q：导入 CSV 中文乱码？**
导出的 CSV 带 BOM（Excel 直接打开不乱码）；导入侧按 UTF-8 解析，请确认源文件编码。

**Q：导入时目标表不存在会怎样？**
按采样值推断类型自动建表（全整数→BIGINT、全数字→DOUBLE、全日期→DATETIME、其余 TEXT），无主键、全可空。建议导入后用设计器补主键与约束。

**Q：导出百万行会内存爆炸吗？**
不会。导出走后端流式响应；SQL dump 每 200 行缓冲刷盘。

## 其他

**Q：Ark 自己的数据存哪？如何重置？**
仓库根 `data/ark.db`（SQLite 单文件）：连接配置、同步任务与报告、Profile、AI 设置。停服后删除即完全重置。

**Q：命令面板里能新建连接吗？**
不能。⌘K 面板提供标签切换、同步入口、主题切换与「新建查询」；新建连接请用连接树顶部 ＋。

**Q：视图会同步吗？**
结构同步支持视图（同方言取原文 `CREATE OR REPLACE VIEW`；跨方言不翻译查询体，原样复制 + 警告）。视图不参与数据同步。
